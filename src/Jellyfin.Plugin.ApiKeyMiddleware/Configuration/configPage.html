Rules

Section: [key name] allow|audit|enforce ([*] applies to keys without a section of their own).
Rule: METHOD /path, where * matches one segment and a trailing ** matches the rest.
allow: no checks; audit: everything is allowed and recorded; enforce: only requests matching a rule get through, the rest get 403.
Invalid lines fail closed: a bad rule is dropped, an unknown mode becomes enforce. Only requests made with an API key are checked, user sessions are not.
